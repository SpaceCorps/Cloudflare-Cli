Contact & Technical Support

We welcome bug reports, enhancement ideas, integration questions, and agentic automation feedback for Cloudflare CLI. Below are the official contact channels.

Primary Support Channels

  • GitHub Issues: For bug reports, unexpected API behavior, or feature requests, visit our issue tracker at github.com/SpaceCorps/Cloudflare-Cli/issues.
  • GitHub Discussions: For automation ideas, integration patterns, and community Q&A, join discussions at github.com/SpaceCorps/Cloudflare-Cli/discussions.
  • Organization: Discover more open-source developer tools by SpaceCorps at github.com/SpaceCorps.

Security Inquiries

To report a security concern or credential storage vulnerability, please file a confidential advisory via GitHub Private Vulnerability Reporting on the repository page.

Cloudflare Platform Inquiries

For questions regarding your Cloudflare subscription, nameserver delegation, DNS propagation, or edge network status, consult cloudflare.com or cloudflarestatus.com.
